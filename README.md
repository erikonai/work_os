## What is WorkOS?

WorkOS is a hierarchical AI operating system built on Claude Code's skill system. Skills are organized under executive personas — CEO at the top, C-suite leaders (CMO, CFO, CPO, CTO, CISO) managing domain-specific capabilities, and a library of community-sourced tools for everything else.

Each skill is a `SKILL.md` file that teaches Claude how to perform a specific task. Skills can be invoked with `/skill-name` in Claude Code.

## Getting Started

### Installation

```bash
# Clone the repo
git clone https://github.com/erikleavell/claude_skills.git
cd claude_skills

# Copy all skills to your Claude skills directory
for dir in */; do
  if [ -f "$dir/SKILL.md" ]; then
    cp -r "$dir" ~/.claude/skills/
  fi
done

# Optionally copy community skills
cp -r community-skills/* ~/.claude/skills/

# Restart Claude Code
```

### Quick Start

```
/ceo                    # Set company context and strategy
/leadership-sync        # Cross-functional health check
/cmo                    # GTM strategy
/cfo                    # Financial planning
/cpo                    # Product strategy
/cto                    # Technical decisions
/ciso                   # Security & compliance
/coach                  # When you need perspective
```

## Creating Skills

Each skill is a folder containing a `SKILL.md` file with YAML frontmatter:

```
skill-name/
├── SKILL.md          # Required: Skill instructions and metadata
├── scripts/          # Optional: Helper scripts
├── templates/        # Optional: Document templates
└── references/       # Optional: Reference files
```

```markdown
---
name: my-skill
description: What this skill does and when to use it.
---

# My Skill

Detailed instructions for Claude on how to execute this skill.
```
